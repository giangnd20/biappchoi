# ShopeeFood QTUX Android App

Ứng dụng Android (sử dụng Kotlin + Jetpack Compose) hỗ trợ tra cứu Bộ Quy Tắc Ứng Xử (QTUX) dành cho Tài xế ShopeeFood.

## Hướng dẫn mở dự án
1. Tải và giải nén tệp `ShopeeFood_QTUX_Kotlin_Source.zip`.
2. Mở **Android Studio**, chọn **Open** và trỏ tới thư mục vừa giải nén.
3. Chờ Gradle tự động Sync dự án.

## Hướng dẫn Build file APK
1. Vào menu **Build** > **Build Bundle(s) / APK(s)** > **Build APK(s)**.
2. Khi hoàn tất, nhấn vào đường dẫn **locate** để lấy file `app-debug.apk`.
